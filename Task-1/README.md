# Task 1 - Personal Portfolio Website

## Purpose
The purpose of this task is to create a responsive personal portfolio website showcasing skills, projects, and contact information. It serves as an interactive resume for a Frontend Developer.

## Flow
1. **Hero Section**: Introduces the developer with a call-to-action button.
2. **About Section**: Provides background information and description.
3. **Skills Section**: Displays proficiency in various technologies (e.g., HTML, CSS, JS) with progress bars.
4. **Projects Section**: Showcases recent projects featuring cards with live demo links.
5. **Contact Section**: Provides a fully validated form for users to get in touch. 

## Fixes Implemented
- The `script.js` was previously empty. I have fully written the JavaScript code to ensure the Contact form's client-side validation logic works, throwing proper visual errors if inputs are omitted. Also, I've added a scrolling effect to the navbar.

## How to Run
1. Open the `Task-1` folder.
2. Double-click the `index.html` file to open it in your default web browser (or use extensions like Live Server in VS Code).
3. Try submitting the contact form empty to verify the validation logic!
